# App policies

Each app policy defines ownership, paths, commands, validation, and risks for GitHub AI routing and CI/CD.

Current app areas:

- `api`: ASP.NET Core backend.
- `frontend`: Vue 3 frontend.
- `extractor`: future safe metadata extraction from AppBuilder databases.
- `infrastructure`: GitHub Actions, security tooling, and repository governance.
- `docs`: SDD, engineering guidance, and AppBuilder analysis.

When a new area becomes real, add a file in this folder and update `.github/apps.yml`.
